# 临时工作目录

此目录存放可以重新生成的过程文件，实际内容不进入 Git。

- `downloads/`：临时下载的参考文件与仓库快照。
- `processing/`：图片裁剪、音频处理、视频转码等中间结果。
- `previews/`：页面截图、预览文件和导出样张。
- `logs/`：开发、构建与检查日志。

一次任务可以使用 `processing/2026-09-07-project-name/` 这样的子目录，避免不同任务互相覆盖。

完成任务后，可清理已经不再需要的对应子目录。原始资料保留在 `materials/`，公开成品放入 `public/`，长期记录放入 `docs/`；不要只在这里保留唯一副本。
